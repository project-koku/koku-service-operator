# COST-7685 Gap Analysis: Implement migration Job lifecycle

**Jira:** [COST-7685](https://redhat.atlassian.net/browse/COST-7685)
**Audited:** 2026-08-10
**Purpose:** Handoff audit of migration Job lifecycle vs ticket acceptance criteria. This document does not update `docs/tasks.md` or other trackers.
**Beta scope:** ROS and Kruize are **out of beta** ([BETA-PRIORITY.md](BETA-PRIORITY.md)). Ticket AC for the ROS migration Job is still **Done** in code, but ROS migrate success is **not** a Cost beta requirement. Cost-only skip of `ROSMigrationJob` (so `SchemaUpToDate` does not wait on ROS) is owned by [COST-8054](../jira/COST-8054.md).

## Verdict

COST-7685 is **done** for ticket acceptance criteria. Sequential Koku → ROS → RBAC (migrate+seed) Jobs, `backoffLimit`/`activeDeadlineSeconds`, succeeded-Job skip, image-tag upgrade recreate, `SchemaUpToDate` True/False with failed Job name, Events, and stage-gated Deployments are all implemented. Remaining deltas are intentional (phase names; combined RBAC migrate+seed) or out of this ticket (upgrade rollback → COST-7693; Cost-only ROS skip → [COST-8054](../jira/COST-8054.md)). The only ticket-adjacent open item is thin controller lifecycle test coverage.

## Done (meets or supersedes ticket intent)

### Resource builders

[`internal/resources/migration.go`](../../internal/resources/migration.go):

| Builder | Job name | Role |
|---------|----------|------|
| `MigrationJob` | `{cfg}-koku-migrate` | Django `manage.py migrate` |
| `ROSMigrationJob` | `{cfg}-ros-migrate` | `./rosocp db migrate up` |
| `RBACMigrationJob` | `{cfg}-rbac-migrate` | migrate + chart-parity seeding in one script |
| `AdminBootstrapJob` | `{cfg}-rbac-admin-bootstrap` | Optional Tenant/Principal bootstrap |

Shared `migrationJob(...)` sets:

- `MigrationBackoffLimit = 3`
- `MigrationDeadlineSeconds = 600`
- `RestartPolicy: OnFailure`
- Annotation `koku.costmanagement.io/image-tag` for upgrade identity
- No `TTLSecondsAfterFinished` (Job existence = completion memory; comment at L496–501)

RBAC seed script changes force recreate via `RBACSeedJobTag(tag) = tag + "-cmseed1"` (`rbacSeedRevision`).

### Lifecycle reconciler

Pipeline stage **Migration** in [`reconcile()`](../../internal/controller/costmanagementserviceconfig_controller.go) (after Validation, before CoreServices).

- `reconcileMigration` — builds step list, runs sequentially (L265–313)
- `runMigrationStep` — create / upgrade-delete / complete / fail / wait (L315–373)
- `isJobComplete` / `isJobFailed` (L757–773)
- Owns Jobs via `SetupWithManager` → `Owns(&batchv1.Job{})`

**Succeeded Jobs not re-run:** completed Job left in place; next reconcile sees `JobComplete` and advances.

**Upgrade re-run:** annotation mismatch → Background delete → next reconcile recreates with new tag. Per-service tags: Koku API, ROS, RBAC (+ seed revision for RBAC steps).

**Migrations before Deployments:** `runPhases` early-exit while migration returns non-zero `Result`; CoreServices/Deployments only run after all migration steps succeed.

### `SchemaUpToDate` + blocking

| When | Status | Reason | Message |
|------|--------|--------|---------|
| Step in progress | False | `MigrationRunning` | `step N/M — {jobName}: {created\|restarting\|running}` |
| Job failed | False | `MigrationFailed` | `{jobName} exhausted retries — check pod logs` |
| All succeeded | True | `MigrationComplete` | `all schema migrations succeeded` |

On failure also sets `Degraded=True`, `PhaseDegraded`, `Result{Stop: true}` (no later stages). On success clears Degraded with `MigrationSucceeded`.

### Events

| Reason | Type | When |
|--------|------|------|
| `MigrationStarted` | Normal | Job Create |
| `MigrationComplete` | Normal | All steps done |
| `MigrationFailed` | Warning | Retries exhausted |

## Intentional deviations (do not treat as bugs)

| JIRA | Implementation | Rationale |
|------|----------------|-----------|
| Phase `Migrating` → `Deploying` | `Progressing` during work; `SchemaUpToDate` for outcome; terminal `Ready`/`Degraded` | [design-vs-jira.md](../design/design-vs-jira.md) §1 — conditions are the machine API; phase enum is `Pending`/`Progressing`/`Ready`/`Degraded` |
| Four Jobs: … RBAC migrate, then RBAC seed | One `RBACMigrationJob` script: `migrate` → `seeds` → cost-management role seed → tenants | Chart parity; documented in tasks.md as “RBAC migrate+seed”; design summary marks migration scope Done |
| “Operator retries up to 3 times” | Kubernetes Job `backoffLimit: 3` + `RestartPolicy: OnFailure` inside one Job object | Matches the ticket’s own Job field requirements; operator does not delete/recreate failed Jobs for extra attempts |
| Optional 4th step | `AdminBootstrapJob` when `spec.rbac.bootstrapAdmin.enabled` + orgAdmin present | Superset of ticket; org-admin bootstrap, not generic RBAC seeding |

## Remaining gaps (ticket-scoped)

None that block accepting COST-7685. Core AC are met under the intentional deviations above.

### G1. Controller lifecycle unit tests — partial (quality)

Evidence: no envtest/unit coverage of `reconcileMigration` / `runMigrationStep` (create → wait → complete → skip; fail → `SchemaUpToDate`/`Degraded`/`Stop`; image-tag change → delete/recreate). Shared Job field assertions (`backoffLimit`/`activeDeadlineSeconds`/`RestartPolicy`) are also untested outside RBAC-focused builder tests. Controller scaffold test does not assert migration behavior.

Impact: regressions in lifecycle gating would only show up in CRC/manual runs. Not a functional AC miss, but the highest-value follow-up for this surface.

## Related gaps (not in Jira body; same surface)

- **COST-7693** owns upgrade rollback: revert Deployment image tags on migration failure, `UpgradeFailed` condition/Event, explicit “block Deployment updates until `SchemaUpToDate`” beyond stage ordering.
- **`MigrationComplete` Event** fires on every successful reconcile pass once Jobs stay complete (no False→True transition guard) — same class of issue noted in COST-7680 gap analysis.
- **Image repository-only change** (same tag) does not re-run migrations; only the `image-tag` annotation is compared.
- **Monitoring alert** `CostManagementMigrationFailed` regex matches `-(koku|ros|rbac)-migrate` but not `*-rbac-admin-bootstrap` ([`internal/resources/monitoring.go`](../../internal/resources/monitoring.go)) — COST-7692 surface.
