# COST-7690 Gap Analysis: Implement UI and ConsoleLink

**Jira:** [COST-7690](https://redhat.atlassian.net/browse/COST-7690)
**Audited:** 2026-08-16
**Purpose:** Handoff audit vs ticket acceptance criteria. Does not update `docs/tasks.md` or other trackers.
**Beta scope:** ROS and Kruize are **out of beta** ([BETA-PRIORITY.md](BETA-PRIORITY.md)); optional install → [COST-8054](../jira/COST-8054.md). `reconcileDelete` ordering that cleans Kruize cluster RBAC after ConsoleLink is incidental ownership hygiene, not a Cost beta deliverable for Kruize. ## Verdict

UI Deployment (oauth2-proxy sidecar + nginx), ClusterIP Service with service-CA TLS, operator-managed cookie Secret / nginx ConfigMap, and cluster-scoped ConsoleLink with finalizer cleanup are implemented under Edge (`reconcileUI`). COST-7690 ticket AC is **done**, including profile-based UI resource sizing (`spec.profile` `standard` / `ha`).

## Done (meets or supersedes ticket intent)

### UI Deployment + oauth2-proxy sidecar

Built in [`UIDeployment`](../../internal/resources/ui.go) (~L145–303), applied from [`reconcileUI`](../../internal/controller/costmanagementserviceconfig_controller.go) (~L579–632):

- Sidecar container `oauth-proxy` (HTTPS `:8443`) + app container `app` running nginx (`:8080`)
- Keycloak OIDC args (`--provider=keycloak-oidc`, issuer, redirect, cookie expire, provider CA; optional `--ssl-insecure-skip-verify`)
- Env from Secrets: cookie `session-secret`, user OAuth `client-id` / `client-secret`
- TLS volume from OpenShift service-CA secret `{cr}-ui-tls`
- Restricted-v2 security contexts via `uiOAuthProxyContainerSC` / `uiAppContainerSC` ([`volumes.go`](../../internal/resources/volumes.go))
- Unit coverage for SCC, `insecureSkipVerify`, writable nginx mounts, SecretRef wiring in [`ui_test.go`](../../internal/resources/ui_test.go)

### Supporting UI config objects (beyond minimal AC wording)

- [`UICookieSecret`](../../internal/resources/ui.go) — create-once operator Secret (`{cr}-ui-cookie-secret`)
- [`UINginxConfigMap`](../../internal/resources/ui.go) — proxies `/api/` to Envoy; synthetic `/api/me`; static UI paths
- OAuth client Secret is **user-provided**; gated via `ValidateUIOAuthClientSecret` + `ConditionUIReady`

### ClusterIP Service + service-CA

[`UIService`](../../internal/resources/ui.go) (~L305–326):

- Port `https` → 8443 → targetPort `https`
- Annotation `service.beta.openshift.io/serving-cert-secret-name: {cr}-ui-tls`
- `spec.type` unset → Kubernetes default **ClusterIP**

### Cluster-scoped ConsoleLink + finalizer cleanup

- Builder [`ConsoleLink`](../../internal/resources/ui.go) (~L360–386): `console.openshift.io/v1`, name `{cr}-cost-management`, `ApplicationMenu` / “Cost Management”, href from discovered cluster domain
- Applied with [`applyClusterScoped`](../../internal/controller/costmanagementserviceconfig_controller.go) (no ownerRef)
- Cleanup in [`reconcileDelete`](../../internal/controller/costmanagementserviceconfig_controller.go) (~L97–122): deletes ConsoleLink (then Kruize CRB/CR) before removing finalizer `costmanagementserviceconfigs.service.costmanagement.openshift.io/cleanup`
- RBAC: `consolelinks` create/delete/get/list/patch/update/watch in [`config/rbac/role.yaml`](../../config/rbac/role.yaml)

### API surface

[`UIConfig`](../../api/v1alpha1/costmanagementserviceconfig_types.go) (~L510–532): `replicaCount`, `oauthProxy` (image/resources/`cookieExpire`), `app` (image/resources), `oauthClientSecretRef`. Condition constant `UIReady`.

## Related gaps (not in Jira body; same surface)

### R1. Thin automated coverage for ConsoleLink / Service / delete path

[`ui_test.go`](../../internal/resources/ui_test.go) covers Deployment/oauth helpers only. No unit tests for `ConsoleLink` fields, `UIService` annotation/ClusterIP default, `UINginxConfigMap`, or `reconcileDelete` ConsoleLink removal ([`ownership_test.go`](../../internal/controller/ownership_test.go) asserts Kruize cluster RBAC cleanup only).

### R2. `UIReady` is not Deployment readiness

Condition becomes True when the OAuth client Secret is valid (~L610–611), before pods are Ready. Downstream edge requeue uses this condition (~L573–575) as an OAuth gate, not a UI availability signal. Cross-cut: [BETA-PRIORITY.md](BETA-PRIORITY.md) T1.

### R3. ConsoleLink `href` empty until discovery

If `status.discoveredConfig.clusterDomain` is unset, ConsoleLink is still applied with `href: ""` ([`ConsoleLink`](../../internal/resources/ui.go) ~L364–368). Link becomes useful only after discovery (COST-7682).
