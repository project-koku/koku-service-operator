# COST-7690 Gap Analysis: Implement UI and ConsoleLink

**Jira:** [COST-7690](https://redhat.atlassian.net/browse/COST-7690)
**Audited:** 2026-08-10
**Purpose:** Handoff audit of UI + ConsoleLink vs ticket acceptance criteria. This document does not update `docs/tasks.md` or other trackers.
**Beta scope:** ROS and Kruize are **out of beta** ([BETA-PRIORITY.md](BETA-PRIORITY.md)); optional install → [COST-8054](../jira/COST-8054.md). `reconcileDelete` ordering that cleans Kruize cluster RBAC after ConsoleLink is incidental ownership hygiene, not a Cost beta deliverable for Kruize.

## Verdict

UI Deployment (oauth2-proxy sidecar + nginx), ClusterIP Service with service-CA TLS, operator-managed cookie Secret / nginx ConfigMap, and cluster-scoped ConsoleLink with finalizer cleanup are implemented under Stage 6 (`reconcileUI`). COST-7690 is **not fully done**: the ticket’s **profile-based resource sizing** acceptance criterion is missing — `spec.profile` is unused and UI resources use hardcoded defaults (or per-component CR overrides only).

## Done (meets or supersedes ticket intent)

### UI Deployment + oauth2-proxy sidecar

Built in [`UIDeployment`](../../internal/resources/ui.go) (~L145–303), applied from [`reconcileUI`](../../internal/controller/costmanagementserviceconfig_controller.go) (~L560–613):

- Sidecar container `oauth-proxy` (HTTPS `:8443`) + app container `nginx` (`:8080`)
- Keycloak OIDC args (`--provider=keycloak-oidc`, issuer, redirect, cookie expire, provider CA)
- Env from Secrets: cookie `session-secret`, user OAuth `client-id` / `client-secret`
- TLS volume from OpenShift service-CA secret `{cr}-ui-tls`
- Restricted-v2 security contexts via `uiOAuthProxyContainerSC` / `uiAppContainerSC` ([`volumes.go`](../../internal/resources/volumes.go))
- Unit coverage for SCC, `insecureSkipVerify`, writable nginx mounts, SecretRef wiring in [`ui_test.go`](../../internal/resources/ui_test.go)

### Supporting UI config objects (beyond minimal AC wording)

- [`UICookieSecret`](../../internal/resources/ui.go) — create-once operator Secret (`{cr}-ui-cookie-secret`)
- [`UINginxConfigMap`](../../internal/resources/ui.go) — proxies `/api/` to Envoy; synthetic `/api/me`; static UI paths
- OAuth client Secret is **user-provided**; gated via `ValidateUIOAuthClientSecret` + `ConditionUIReady`

### ClusterIP Service + service-CA

[`UIService`](../../internal/resources/ui.go) (~L305–326):

- Port `https` → 8443 → targetPort `https`
- Annotation `service.beta.openshift.io/serving-cert-secret-name: {cr}-ui-tls`
- `spec.type` unset → Kubernetes default **ClusterIP**

### Cluster-scoped ConsoleLink + finalizer cleanup

- Builder [`ConsoleLink`](../../internal/resources/ui.go) (~L360–386): `console.openshift.io/v1`, name `{cr}-cost-management`, `ApplicationMenu` / “Cost Management”, href from discovered cluster domain
- Applied with [`applyClusterScoped`](../../internal/controller/costmanagementserviceconfig_controller.go) (no ownerRef)
- Cleanup in [`reconcileDelete`](../../internal/controller/costmanagementserviceconfig_controller.go) (~L97–122): deletes ConsoleLink (then Kruize CRB/CR) before removing finalizer `costmanagementserviceconfigs.service.costmanagement.openshift.io/cleanup`
- RBAC: `consolelinks` verbs in [`config/rbac/role.yaml`](../../config/rbac/role.yaml)

### API surface

[`UIConfig`](../../api/v1alpha1/costmanagementserviceconfig_types.go) (~L497–519): `replicaCount`, `oauthProxy` (image/resources/`cookieExpire`), `app` (image/resources), `oauthClientSecretRef`. Condition constant `UIReady`.

## Remaining gaps (ticket-scoped)

### G1. Profile-based resource sizing — missing

Ticket AC requires profile-based sizing. `Profile` enum (`standard` / `ha`) exists on the CR ([`types.go`](../../api/v1alpha1/costmanagementserviceconfig_types.go) ~L41–45), but **no Go code reads `cfg.Spec.Profile`** for UI (or any workload).

UI fallbacks when `Resources.Limits == nil` are fixed constants in [`UIDeployment`](../../internal/resources/ui.go) (~L164–177):

| Container | Requests | Limits |
|-----------|----------|--------|
| oauth-proxy | 50m / 64Mi | 100m / 128Mi |
| app (nginx) | 50m / 64Mi | 100m / 128Mi |

Per-component overrides (`spec.ui.oauthProxy.resources`, `spec.ui.app.resources`) and `replicaCount` exist, but nothing keys replicas/resources off `standard` vs `ha`. Cross-ticket: same gap tracked under COST-7678 (sizing maps) and mentioned for COST-7686/7693 in `docs/tasks.md`.

**Impact:** HA profile does not change UI footprint; ticket AC #4 unmet.

## Related gaps (not in Jira body; same surface)

### R1. Thin automated coverage for ConsoleLink / Service / delete path

[`ui_test.go`](../../internal/resources/ui_test.go) covers Deployment/oauth helpers only. No unit tests for `ConsoleLink` fields, `UIService` annotation/ClusterIP default, `UINginxConfigMap`, or `reconcileDelete` ConsoleLink removal ([`ownership_test.go`](../../internal/controller/ownership_test.go) asserts Kruize cluster RBAC cleanup only).

### R2. `UIReady` is not Deployment readiness

Condition becomes True when the OAuth client Secret is valid (~L591–592), before pods are Ready. Downstream edge requeue uses this condition (~L554–556) as an OAuth gate, not a UI availability signal.

### R3. ConsoleLink `href` empty until discovery

If `status.discoveredConfig.clusterDomain` is unset, ConsoleLink is still applied with `href: ""` ([`ConsoleLink`](../../internal/resources/ui.go) ~L364–368). Link becomes useful only after discovery (COST-7682).
