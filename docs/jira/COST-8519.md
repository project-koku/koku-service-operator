# COST-8519: Fix operator monitoring labels and namespace scope

**Jira:** [COST-8519](https://redhat.atlassian.net/browse/COST-8519)
**Type:** Task
**Status:** In Progress
**Priority:** Normal
**Component:** Operators

## Implementation

- Renamed operator metric labels that collide with Prometheus scrape-target labels:
  `namespace` → `cr_namespace`, `job` → `migration_job`, `pod` → `managed_pod`,
  and `container` → `managed_container`.
- Moved the operator `ServiceMonitor` and operator `PrometheusRule` to singleton
  bundle resources in the operator namespace so AllNamespaces deployments can
  observe CMSCs outside that namespace.
- Kept application-metric monitors and alerts per CMSC, and removed the legacy
  per-CMSC operator `ServiceMonitor` during reconciliation.

## Release note

Operator alert labels now identify the failed migration Job and managed Pod
without colliding with Prometheus target labels. Operator alerts are installed
in the operator namespace and can report CMSCs in other namespaces.
