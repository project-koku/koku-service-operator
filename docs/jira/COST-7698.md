## Description

Deliver E2E tests for operator-specific behaviors:* Drift correction -- modify a managed resource manually and verify the operator reverts it on the next reconciliation

- Secret rotation -- set the rotate-secrets annotation and verify new key is generated, Deployments are restarted, and annotation is removed
- Upgrade sequencing -- change image version and verify migrations run before Deployment rollout
- Dependency failure conditions -- make an external dependency unreachable and verify correct condition is set
- Pause/resume -- set pause annotation and verify reconciliation stops; remove it and verify it resumes

### Out of Scope

- Application behavior tests (covered in story 21)
