## Description

Deliver automated CI that runs on every PR to the operator repo:* Prow step definition -- register a CI step in the OpenShift CI step registry (script + ref YAML) that triggers on PR events

- Operator install via OLM -- build operator image from PR branch, create CatalogSource, install operator through OLM subscription (validates real OLM lifecycle)
- External prerequisites provisioning -- deploy PostgreSQL, Kafka, OIDC provider, and S3-compatible storage on the ephemeral test cluster (similar to existing Helm chart CI using S4 + RHBK + AMQ Streams)
- E2E suite execution -- create CostManagement CR, wait for Ready phase, run the adapted pytest suite (story 21) and operator-specific scenarios (story 22)
- Artifact collection -- save JUnit XML, operator logs, pod descriptions, events, and CR status to GCS for debugging failures via download-ci-artifacts.sh
- Failure reporting -- surface test results in PR checks with clear pass/fail status

### Out of Scope

- Multi-version OCP compatibility matrix (future), nightly/periodic jobs
